# Installer Updates 1.0.4

Safer tool downloads and a safer default folder for tools.

## Tools
- FFmpeg is now installed from a fixed version (9.0.2) and verified against a SHA256 stored in the installer, not one fetched from the download server.
- New installs put tools under your user profile (Sakugaloader\Tools in Local AppData) instead of the root of drive C. If you already have tools in the old folder they keep being used.

## Installer
- Everything from 1.0.3: What's new panel, latest Sakugaloader version and one-click Update now.
