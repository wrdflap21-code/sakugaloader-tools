# Installer Updates 1.0.3

The installer now tells you what changed and which Sakugaloader is the latest.

## What's new panel
- A What's new button next to the version (and on the update notice) opens the release notes of the installer, with sections, like an in-app changelog.

## Latest Sakugaloader
- The Panel tab shows the latest published Sakugaloader version next to the installed one, with UP TO DATE or UPDATE AVAILABLE.
- When a newer Sakugaloader exists, the Install button becomes Update Sakugaloader.

## Updates
- The update notice has a What's new button, so you can read the changes before pressing Update now.
